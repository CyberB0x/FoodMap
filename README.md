# 🗺 Nearby Places Explorer

Nearby Places Explorer is a web application that allows users to discover places around them using Google Maps and Google Places API.

The app helps users find nearby restaurants, cafes, shops, hotels, and other points of interest, view ratings and photos, and build routes to selected places.

---

## 🚀 Features

- 📍 User geolocation
- 🗺 Interactive Google Map
- 🔍 Nearby places search (Google Places API)
- 🧭 Route building (Google Directions API)
- 🖼 Place photos via Place Details
- ⭐ Rating filter
- 🧩 Place type filters:
  - 🍽 Restaurants
  - ☕ Cafes
  - 🛍 Shops
  - 🏨 Hotels
  - ⛽ Gas stations
  - 🏥 Hospitals
- 🔎 Autocomplete search by place name
- 📱 Clean Sidebar UI
- 🪟 InfoWindow with place details

---

## 🧑‍💻 Tech Stack

- React
- Google Maps JavaScript API
- Google Places API
- Google Directions API
- @react-google-maps/api
